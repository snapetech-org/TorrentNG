TorrentNG now lets each browser choose an interface language. Navigation, language settings, and the Add Torrent dialog use translated labels and intake guidance in twelve locales with English fallback. Torrent names, URLs, and paths remain unchanged; Arabic translated labels carry local right-to-left metadata while the rest of the app stays English and left-to-right.
