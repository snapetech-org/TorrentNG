TorrentNG Desktop
=================

Run `torrentng-desktop` (or TorrentNG.exe / TorrentNG.app). On first launch pick:

  * This computer  - the bundled engine (`torrentngd`, next to this app) is started
                     on loopback only and stopped when you close the window.
  * Another machine - enter the URL and API token of a TorrentNG server.

Settings live in:
  Linux    ~/.config/torrentng-desktop/config.toml
  macOS    ~/Library/Application Support/TorrentNG Desktop/config.toml
  Windows  %APPDATA%\TorrentNG Desktop\config.toml

Docs: https://github.com/snapetech/TorrentNG/blob/main/docs/DESKTOP.md
