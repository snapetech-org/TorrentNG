# Observation artifacts

The summaries, client logs, and raw `smaps`/metrics diagnostics are the retained
run evidence. Temporary session databases and local API/bootstrap tokens are
excluded. Generated payload copies are excluded because some are 128 or 256
MiB, larger than GitHub's single-file limit, and the probe can regenerate them
from the recorded size and deterministic seed. The archived runs used seed
`20261022` (the probe default). Their payload hashes are recorded in each
summary and in the report. Current probe summaries also record `fixture_seed`
explicitly.

Payloads can be regenerated by rerunning
[`native_seed_cpu_ram_probe.py`](../../../../scripts/native_seed_cpu_ram_probe.py)
with the same `--size` and `--seed 20261022`. The matched rTorrent binary and
runtime libraries remain task-local benchmark inputs and are identified by
their hashes and paths in the summaries.
